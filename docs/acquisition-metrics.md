# Acquisition Metrics

## Purpose

Measure early user interest, landing page performance, and prototype engagement for the Smart Study Group Finder system.

---

## Required Metrics

| Metric ID | Metric Name | What It Measures | Formula / Counting Method | Data Source | Target / Success Criterion |
|-----------|-------------|------------------|---------------------------|-------------|----------------------------|
| M-01 | Landing Page Views | Number of visitors who opened the landing page | Count total page visits | GitHub Pages / Manual Log | At least 30 views |
| M-02 | CTA Clicks | Number of users who clicked the "Try Demo" button | Count CTA button clicks | Landing Page Script / Manual Count | At least 15 clicks |
| M-03 | Prototype Visits | Number of users who opened the Smart Study Group Finder prototype | Count prototype visits | Prototype Link / Manual Log | At least 10 visits |
| M-04 | User Registrations | Number of users who created an account | Count successful registrations | Local Storage / Prototype Data | At least 8 registrations |
| M-05 | Group Creation Rate | Number of study groups created by users | Count created study groups | Local Storage | At least 5 study groups |

---

## Interpretation

If the acquisition metrics are below the target, the team will:

- Improve the landing page headline and design.
- Make the CTA button more visible and attractive.
- Simplify the registration process.
- Share the prototype through more student channels (Facebook, Telegram, class groups).
- Collect additional user feedback and improve the prototype based on suggestions.
