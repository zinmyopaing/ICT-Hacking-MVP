## Notes

The landing page introduces the Smart Study Group Finder, explains the target users, user problem, proposed solution, and available prototype features.

The **Try Demo** and **Explore Study Groups** buttons connect the landing page to the working find-group.html prototype screen.

The **Login** button connects users to the prototype login page.

The landing page uses the same visual style and project information as the final prototype. It only presents features that are currently implemented or planned in the approved final prototype requirements.

The landing page also includes a short privacy statement explaining that only necessary information is collected for study-group participation.
